## Final Translation

### 《大脑设计》（Design for a Brain）

这是一篇依据声誉而作的评论。我们读过的每一本讨论计算机与心智的书，都在参考
书目和脚注中显著提到 Ashby 的著作。它技术性很强，读起来不轻松，但为了领会这项
奠基性工作的洞见，值得一读。

#### 最优与可接受

寻找最优值，要比寻找一个符合既定标准的可接受值复杂得多。假设一个人来到外国
市场，那里有 `100` 种他完全陌生的水果。要找出最合自己口味的品种，他必须：
（1）尝遍 `100` 种；（2）至少作 `99` 次比较；（3）记住结果，以便最终回头找到
最优的那个品种。另一方面，要找一种可以接受的水果，他只需依次或随机试吃，完全
不必费心记住先前的结果，碰到第一种通过检验的就停下来。因此，要求最优可能过了
头；生物系统所需要的，不过是让有机体找到“一个状态，或一个处在给定界限之间的
值”。

#### 地球上生命的发展

所以，地球上生命的发展不应被看成什么非凡之事。恰恰相反，它是不可避免的。
这里所谓不可避免，是说：如果一个像地球表面那么大的系统，基本上是多稳态的，并且
在动力学上保持温和沸腾达 `5,000 million` 年（`50 亿年`），那么除非出现奇迹，
否则没有什么能让系统避开这样的状态——在其中，各个变量聚合成具有强烈自我保存
能力的形式。

#### 学习机制

这就是学习机制。它的特殊之处在于，基因模式把一部分对有机体的控制权交给了环境。
因此，它并不详细规定一只小猫该怎样捉住老鼠，而是给小猫提供一种学习机制和玩耍的
倾向；这样一来，正是老鼠教会小猫捕鼠的精微之处。

#### 移位寄存器与逻辑门图

图中 `X REGISTER`（X 寄存器，位序 `X₃ X₂ X₁ X₀`）在第一次移位前为 `0 1 0 0`，
第一次移位后为 `0 0 1 0`；`Y REGISTER`（Y 寄存器，位序 `Y₃ Y₂ Y₁ Y₀`）则由
`1 0 1 1` 变为 `0 1 0 1`。两者接入标有 `Cᵢ / Sᵢ` 的 `ADDER`（加法器）和一个

第二次移位后：1 1 0 0 0
第三次移位后：1 1 1 0 0
第四次移位后：1 1 1 1 0
第五次移位后：0 1 1 1 1

#### 图 10：模拟瀑布

在这项计算机实验中，模拟的瀑布越过悬崖边缘，飞溅到下方水池里。实验由洛斯阿拉莫斯

#### 计算机恰好是人所不是的东西

计算机几乎恰好是人所不是的东西。它可以把全部注意力持续放在无穷无尽的细节上；
它不受干扰，精确而可靠；最错综复杂、最漫长的计算，它也能轻松完成，毫无差错，
所用时间还远不到人类完成同一任务所需时间的百万分之一。它没有情绪——至少我们
这样认为。它既不会厌倦，也不会疲劳。只需告诉它一次；此后，它会完美地记住，
直到有人叫它忘掉；到那时，它又会立即而彻底地忘掉。

### HP 9100A 计算器

新式桌面数值运算机里最出色的，就是这台 Hewlett-Packard 机器。它可以编程，
用途广泛，而且安静——在这些方面都胜过竞争产品。Portola Institute 目前正用
9100A 帮助孩子们尽早掌握计算机；它是一件极好的探究工具。

#### 规格

9100A 可以进行加、减、乘、除、平方根、`log x`、`ln x`、`eˣ`、`sin x`、
`cos x`、`tan x`、`sin⁻¹ x`、`cos⁻¹ x`、`tan⁻¹ x`、`sinh x`、`cosh x`、
`tanh x`、`sinh⁻¹ x`、`cosh⁻¹ x`、`tanh⁻¹ x`，以及极坐标与直角坐标之间的
双向变换。

- 数值范围：`10⁻⁹⁹` 至 `10⁹⁹`；
- 磁芯存储器共有 `19` 个寄存器：`3` 个显示寄存器、`16` 个存储寄存器；
- 显示方式：十进制或浮点表示；
- 程序容量：`196` 步；
- 编程方法：按正确顺序按键，不需要专门的编程语言；
- 程序可存入钱包大小的磁卡；
- 典型运算耗时：`2–280` 毫秒；
- 机器重量：`40` 磅；
- 尺寸：`8 × 16 × 19` 英寸深；
- 据称即将推出的附件：打印机、`xy` 绘图仪、输入／输出接口。
