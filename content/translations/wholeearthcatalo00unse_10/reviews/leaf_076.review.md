# Leaf 076 Review

## Conclusion

accepted

## Reasons

- n76／PDF 77／印刷页 75 的映射正确。600 dpi 整页与 1,200 dpi 六块定点图支持两条
  主记录：编号 `10` 的 The Radio Amateur's Handbook，以及 R. Buckminster Fuller
  的 Education Automation。50 Mc 电台、原理图、三本小册子、Q 简语、电磁场摘文与
  电报码均属于前一记录；儿童案例、五段 Fuller 引文、书封和订购块属于后一记录。
- 页界正确：n75 的 Allied、Heathkit、Tektronix 与 The Radio Master 在前页结束；
  n77／印刷页 76 从 American Booksellers Association 另起。译稿没有跨页补入
  相邻记录的正文、图签或书目。
- 手册的 `10a / 10b` 评论完整保留 `43` 年、电路基础、执照法律、实际电路、完整制作
  细节、表面简单却费时费技术，以及 Heathkit 判断。Bill English／Arthur Brand
  署名、计算机打印与随意拼写说明、地下无线电网络和“长发族”段落均已收入；原页
  `pracitcal / apparant / build then` 等有意保留的英文错字没有被机械制造成中文错字。
- 主书目准确：American Radio Relay League，`1925…1969 / 611 pp.`，美国邮资付讫
  `$4.00`、加拿大 `$4.50`、其他地区 `$5.50`，以及 `Newington, Conn. 06111` 地址
  均与页面一致。
- 图 19-6 的标题、`50 Mc`、晶体管电台、麦克风／电池／天线、总重不足 `3 lb`、
  塑料零件盒中的天线耦合器、随机“长线”、同轴馈电天线和机顶 BNC 接头均准确；
  `dit / dah / didah` 作为声音语言的说明也完整保留。
- 图 19-8 的四块结构 `TRANSMITTER / RECEIVER / MODULATOR / ALTERNATE CIRCUIT
  FOR TRANSMITTER` 及 `OSC / AMP / RF AMP / MIXER OSC` 均正确。图签约定准确：
  合成电阻默认 `1/2 W` 或更低，`C1-C7` 为浸渍银云母电容器，其余默认为陶瓷电容器；
  十进制值用 `µF`，其余默认用 `pF`。
- 三本小册子的独立条目、功能和价格均准确：Understanding Amateur Radio 保留
  低成本设备、最高 `150 W`、甚高频／测量／天线内容及 `$2.50 U.S.A. / $3.00
  Elsewhere`；How to Become a Radio Amateur 保留 Novice class、模块扩展性与
  `$1.00`；The Radio Amateur's License Manual 保留政府考试问答与 `$1.00`。
- 五条 Q 简语 `QRG / QRH / QRI / QRJ / QRK` 的英语问答、等级次序和 `kc` 单位均
  保持为源语言样例，没有被翻译或改写。电场／磁场的“原因—结果—场”、场强／方向、
  力与势能关系也完整准确。
- 二十二组报码全部覆盖且配对无误：`TMW / TNX-TKS / TT / TU / TVI / TXT /
  UR-URS / VFO / VY / WA / WB / WD-WDS / WKD-WKG / WL / WUD / WX /
  XMTR (TX) / XTAL / XYL (YF) / YL / 73 / 88`；英语释义均与页面一致。
- Education Automation 的分类说明、`1962 / 88 pp. / $1.95 postpaid`、副题、作者、
  Southern Illinois University Press、`600 West Grand / Carbondale, Illinois 62903`
  及 WHOLE EARTH CATALOG 购买方式均准确。儿童案例完整保留两岁半、电动打字机、
  彩色按键／指甲、隐藏电开关、正确手指闭合电路、窗口大写字母及三岁盲打故事。
- Fuller 前四段引文均忠实：教育成为头号世界产业与跨洲纪录片调取系统；物理任务地理
  尺度越大而概念头脑越迟钝；校园应像可变换的马戏团；数据转交工具、尺寸详图过时及
  自动化实现思考。第五段的去根、`10%`、下一次选举 `25%`、地理代议制与地方政治
  机器论述也完整准确。
- 同审最小回归确认唯一必修已闭环：“再下一次选举，可能连半数人都没有投票资格”
  准确表达 `less than the majority will be able to vote`，即有投票资格者不足半数；
  相邻的 `10%`、`25%`、搬迁原因和下一段政治基础论述均未被改动。

## Required Fixes

- 无。上一轮唯一必修已按源页和 reviewer 要求修正。

## Residual Risks

- 图 19-8 的元件代号和数值极小且与线路重叠；现译文只陈述清楚可辨的分区标签与图签
  约定，没有从现代电路资料补值。后续不应把图中模糊字符转写为新的正文规格。
- Q 简语原页用不等长的连续句点表示待填项，且 QRK 最后一处括号／句点排印不完整；
  现译文统一为省略号并保留全部英语词句与等级，没有补造通信内容。
- Fuller 引文中的投票比例、居住期限制与政治预测，以及全页技术单位、价格和考试说明，
  均是 1969 年历史材料，不应在后续排版中改写成当前事实或法规。
