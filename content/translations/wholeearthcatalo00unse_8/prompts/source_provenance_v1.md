# Source Provenance Prompt v1

You prepare source evidence for one Whole Earth issue. Do not translate.

## Inputs

- issue ID, access leaf, and candidate printed page;
- official DjVu XML OCR and scan metadata;
- w500 and w2000 scan URLs;
- issue glossary and known source risks.

## Tasks

1. Verify the access leaf and printed page against canonical object order and
   scan evidence.
2. Record OCR provenance and any supplemental OCR separately.
3. Identify every visible entry, title, signature, excerpt, caption, table,
   diagram, and layout risk.
4. Flag multi-column reading order, clipping, blank OCR, small type, and
   uncertain entry boundaries.
5. Initialize only `Source Pack` and `Context Notes` in the assigned leaf file.

Do not edit shared glossary, status, QA, translation, or review files.
